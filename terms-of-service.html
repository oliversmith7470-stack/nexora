5. YouTube API Services compliance

NEXORA uses YouTube API Services, including the YouTube Data API and YouTube Analytics API.

Its authorised YouTube OAuth scopes are limited to:

  • yt-analytics.readonly
  • youtube.readonly

These are the only two YouTube OAuth scopes requested by NEXORA.

The Analytics API collection is restricted to six non-monetary metrics:

  • views
  • estimatedMinutesWatched
  • averageViewDuration
  • averageViewPercentage
  • audienceWatchRatio
  • relativeRetentionPerformance

NEXORA does not request monetary, write or partner scopes.

Use of YouTube API Services is governed by the YouTube API Services Terms of Service and the YouTube API Services Developer Policies.

These requirements include applicable rules concerning data use, access, security, retention and deletion.

The relevant privacy and data-handling practices are explained in the NEXORA Privacy Policy.

6. Privacy and data handling

NEXORA maintains a separation between public competitor observations and the owner's private channel Analytics.

Owner-private Analytics are intended exclusively for the authorising owner.

They are not sold, shared with third parties, used for advertising or made available to anyone other than the authorising owner.

NEXORA does not perform cross-channel or cross-owner aggregation and does not combine owner-private Analytics with public competitor information in mixed comparisons.

The retention periods and deletion procedures are specified in the Privacy Policy.

Revoking access stops collection immediately. Applicable deletion procedures then apply.

Credentials and access tokens must never be placed in Analytics records, logs or tests, printed or hardcoded.
